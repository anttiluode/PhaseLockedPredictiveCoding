This is an explicit global template-alignment controller with reduced band-window XOR storage—not unchanged GN27 neurons, an automatically learned clock, a Kalman filter, or a demonstrated biological theta–gamma mechanism. The readout phase is selected by comparing three stored frames.

03 / What the circuit computes

Top-down phase selection

δ* = argmin δ∈{−1,0,+1}
Hamming(Wₜ, R[t + δ])

Each candidate is a complete stored frame. A single winning offset is broadcast to all bit-plane memories.

Local windowed XOR update

eᵢ = Wᵢ XOR Rᵢ[t + δ*]
Rᵢ' = Rᵢ XOR eᵢ = Wᵢ

The update is computed by a truth-table equivalent of the original reduced window band's write/erase response. This does not learn a new period or a motion law.

Three ways to break it: ±2 timing changes exceed the hub's ±1 search range; two independently shifted regions cannot both be aligned by one global offset; and an actual scene change that exactly matches another stored phase is observationally indistinguishable from timing jitter. These limitations are part of the experiment, not hidden bugs.

The complete matched controls are in the deterministic benchmark. It also compares a per-pixel independent phase choice and a three-tick sustained-error filter, showing when each suppresses genuine novelty. The animated page is a reduced visual laboratory, not a measured energy-efficiency result.
